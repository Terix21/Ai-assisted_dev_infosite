# AI-Assisted Development: Code Quality, Security & Human Oversight

A self-contained, offline HTML presentation by Patrick Pierre-Louis, Software Engineer.

The presentation explains how developers can use AI assistance responsibly while retaining human accountability for code quality, security, permissions, dependencies, data handling, and merge decisions.

## Open the presentation

Open [`ai-assisted-development.html`](ai-assisted-development.html) in a modern desktop browser. It has no external runtime dependencies, remote fonts, analytics, or network calls.

The file opens in the presenter console. Select **Launch presentation view** to open the synchronized audience window. Keep the presenter console on the private display and move the audience window to the projected display.

## Presentation controls

In the presenter console, use the arrow buttons or keyboard arrows to navigate. `P` launches the audience view, `N` shows notes, `F` toggles full screen, `B` blacks out the audience view, `G` opens Go Deeper, `S` opens Sources, and `R` opens reading view. The timer target defaults to 45 minutes.

## Accessibility and printing

The deck supports keyboard navigation, visible focus, screen-reader announcements, reading view, and reduced-motion preferences. Use the browser’s print command from reading view to produce a handout.
