# Resources

These public resources support the examples and guidance in the presentation. Review the original sources and your organization’s policies before applying a practice to production work.

## Secure software practice

- [NIST Secure Software Development Framework (SP 800-218)](https://csrc.nist.gov/pubs/sp/800/218/final) — Secure development practices, review, testing, and response.
- [OWASP Authorization Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html) — Least privilege, deny by default, and permission checks.
- [OWASP Secrets Management Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Secrets_Management_Cheat_Sheet.html) — Credential lifecycle and access controls.
- [OWASP SQL Injection Prevention Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/SQL_Injection_Prevention_Cheat_Sheet.html) — Prepared statements and parameterized queries.
- [Pro Git: Recording Changes to the Repository](https://git-scm.com/book/en/v2/Git-Basics-Recording-Changes-to-the-Repository) — Diffs, staging, and commits.

## AI-assisted development and agents

- [GitHub Copilot Agents: Responsible Use](https://docs.github.com/en/copilot/responsible-use/agents) — Capabilities, limitations, and human evaluation in agentic workflows.
- [Pillar Security: Rules File Backdoor](https://www.pillar.security/blog/new-vulnerability-in-github-copilot-and-cursor-how-hackers-can-weaponize-code-agents) — A public demonstration of how poisoned rules files can influence code agents. It is not evidence of a widespread customer breach.
- [USENIX Security 2025: “We Have a Package for You!”](https://www.usenix.org/conference/usenixsecurity25/presentation/spracklen) — Research on package hallucinations and software supply-chain implications. Results depend on tested models and settings.

## Example documentation

- [React: dangerouslySetInnerHTML](https://react.dev/reference/react-dom/components/common#dangerously-setting-the-inner-html) — Handling raw HTML safely in React.
- [node-postgres: Queries](https://node-postgres.com/features/queries) — Parameterized queries in a JavaScript database client.
